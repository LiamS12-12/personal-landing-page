# Personal Landing Page

Personal landing page for CS 506, deployed to AWS S3.

## Week 3 Release: v0.1.0

This release integrates the Week 3 lightbox gallery starter into my existing landing page.

The site includes:

- My existing portfolio landing page content
- My own images
- A clickable lightbox gallery
- JavaScript and CSS from the Week 3 starter
- Deployment to the same S3 bucket used in Week 1

## Local Development

Install dependencies:

npm install

Run the local server:

npm run serve

Then open:

http://localhost:8080

## Deployment

Upload the updated files to the existing S3 static website bucket, preserving the folder structure:

index.html
style.css
css/lightbox.css
js/lightbox.js
images/
